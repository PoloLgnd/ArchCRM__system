# Документация CRM системы

## Для чего она нужна?
Я делаю эту CRM систему для тренировки и для того чтобы понять, как все это происходит, как выглядят такие модели и как они устроены.

## Как запустить проект?

Для того чтобы запустить проект вам надо выполнить вот такие команды в зависимости от вашей OC:

==Windows==
```powershell
python -m venv venv
venv/Scripts/activate
```

==LInux==
```Bash
python3 -m venv venv
source venv/bin/activate
```

Установите зависимости
```
pip install -r requirements.txt
```

Запустите приложение

```
python app.py
```
